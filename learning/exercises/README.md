# Ćwiczenia (sesje praktyki kodowej)

Krótkie zadania, które sprawdzają, czy przerobiona wiedza **przychodzi do głowy sama w nowych sytuacjach**. Zasady sesji są w [`CLAUDE.md`](../../CLAUDE.md#sesje-praktyki-kodowej).

## Struktura

```
learning/exercises/
├─ NNNN-krotki-opis/
│  ├─ zadanie.md        # polecenie (bez nazwy tematu, to część ćwiczenia)
│  └─ start.ts(x)       # kod startowy, jeśli zadanie go potrzebuje
└─ _rozwiazania/
   └─ NNNN.md           # rozwiązanie wzorcowe, zapisane PRZED pokazaniem zadania
```

## Jak pracować

1. Przeczytaj `zadanie.md`. Jeśli nie rozumiesz polecenia, pytaj od razu: wyjaśnienie polecenia nie jest podpowiedzią.
2. Rozwiązuj w edytorze albo w głowie. W czacie podaj odpowiedź, **pewność** (25 / 50 / 75 / 95%) i krótko tok myślenia.
3. Utknąłeś? Napisz „podpowiedź”. Dostaniesz jeden szczebel drabinki naraz.
4. **Nie otwieraj `_rozwiazania/`** przed zakończeniem zadania. Rozwiązanie jest zapisane wcześniej po to, żeby ocena była uczciwa, a nie żeby było pod ręką.
