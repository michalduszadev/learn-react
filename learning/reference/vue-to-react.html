Vue 3 → React 19

Odpowiedniki pojęć z Vue/Nuxt w React. Kolumna „Uwaga” mówi, gdzie analogia się psuje, i to jest najważniejsza część tej ściągi. Będzie rosła z kolejnymi lekcjami.

Komponenty i szablon

PojęcieVue 3React 19Uwaga
Komponent<script setup> + <template>funkcja zwracająca JSXsetup wykonuje się raz, funkcja Reacta przy każdym renderze (0001).
Interpolacja{{ name }}{name}W JSX klamry przyjmują dowolne wyrażenie JS.
Atrybuty:href="url"href={url}class → className, for → htmlFor, camelCase dla zdarzeń.
Klasy warunkowe:class="{ active: on }"className={on ? 'active' : ''}Brak wbudowanej składni obiektowej; popularna jest mała biblioteka clsx.
v-if<p v-if="ok">{ok && <p/>} albo {ok ? <A/> : <B/>}Uważaj na {count && …}: dla 0 wyrenderuje „0” (Conditional Rendering).
v-showv-show="ok"hidden={!ok} lub stylDo zachowania stanu ukrytego drzewa: <Activity> (React 19.2).
v-forv-for="o in offers" :key="o.id"{offers.map(o => <Row key={o.id} />)}key stabilny i unikalny, nigdy indeks przy listach, które się zmieniają (Rendering Lists).
v-htmlv-html="raw"dangerouslySetInnerHTML={{ __html: raw }}Nazwa jest ostrzeżeniem: ryzyko XSS, sanityzuj.
