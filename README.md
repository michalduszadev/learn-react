# Job Tracker

Aplikacja do śledzenia procesów rekrutacyjnych z dopasowaniem ofert, a jednocześnie mój projekt do nauki Reacta i fullstacku po latach pracy z Vue/Nuxt.

> 🚧 W budowie. Postęp: [`ROADMAP.md`](ROADMAP.md)

## Co będzie umiała

- Zapisywanie ofert pracy i śledzenie etapów rekrutacji
- Filtrowanie i statystyki procesu
- Analiza wklejonego ogłoszenia przez LLM: wyciągnięcie wymagań i ocena dopasowania do mojego profilu

## Stack (docelowo)

React 19 + TypeScript · TanStack Query · Zustand · React Hook Form + Zod · Next.js · NestJS · PostgreSQL · Vitest, Testing Library, Playwright · Docker · GitHub Actions · chmura · Claude API

Dlaczego ten stack: przed startem przeanalizowałem 667 ofert frontend/fullstack z pięciu portali oraz najnowsze badania branżowe (Stack Overflow 2026, State of JS 2025, GitHub Octoverse 2025).

## Jak się uczę

Kod piszę sam. Asystent AI pełni rolę mentora: wyjaśnia, podpowiada stopniowo, robi code review i quizy. Materiały z nauki (lekcje, ściągi, dziennik postępów) są w [`learning/`](learning/).
